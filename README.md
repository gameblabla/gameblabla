## 🕹️ Emulators

- [**multiRexZ80**](https://github.com/gameblabla/multirexz80) – Multi Z80 emulator  
- [**PCFXEmu**](https://github.com/gameblabla/pcfxemu) – PC-FX / PC-FXGA emulator  
- [**GP32Emu**](https://github.com/gameblabla/gp32emu) – Improved GP32 emulator  
- [**BDMEmu**](https://github.com/gameblabla/BDMEmu) – Bandai Design Master emulator  
- [**TerebikkoEmu**](https://github.com/gameblabla/TerebikkoEmu) – Terebikko / Mattel See ’N Say emulator  
- [**VBEmu**](https://github.com/gameblabla/vbemu) – Fast Virtual Boy emulator, forked from Mednafen  
- [**VBA Next Standalone**](https://github.com/gameblabla/vba-next-portable) – Optimized standalone VBA Next port  
- [**Fast Oswan**](https://github.com/gameblabla/oswan) – Very fast WonderSwan emulator  
- [**SwanEmu**](https://github.com/gameblabla/swanemu) – Fast and accurate WonderSwan Color emulator

## 🧪 Tools & Experiments

- [**PC-98 Launcher Editor**](https://github.com/gameblabla/pc98launcher_editor) – Win32 app for PC-98Launcher  
- [**PMD Tools**](https://github.com/gameblabla/pc98sndpmdtools) – Tools for the PC-98 PMD music tracker  
- [**EXP3DO SDK**](https://github.com/gameblabla/exp3DOsdk) – Modern 3DO development toolchain using GCC 8.5  
- [**GameTranslate Local**](https://github.com/gameblabla/gametranslate-local) – Simple app using local LLMs via llama.cpp to translate game text from an HDMI capture card  
- [**Simple Game Library**](https://github.com/gameblabla/another_gameblabla_library) – Lightweight SDL1 / SDL2 library  
- [**DOS Playground**](https://github.com/gameblabla/dosplayground) – Code experiments for MS-DOS  
- [**RGB Image Decoder / Encoder**](https://github.com/gameblabla/decoder_encoder_rgb) – Binary ↔ RGB565 converter  
- [**Clock App**](https://github.com/gameblabla/clock_sdl_app) – Minimal SDL clock app  
- [**Visual Novel Engine**](https://github.com/gameblabla/visual_novel_engine) – Framerate-adaptive visual novel engine
